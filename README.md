# Text Formatting Everywhere — Unofficial 1.20.1 Fabric Backport

A small compatibility backport of [Text Formatting Everywhere](https://modrinth.com/mod/text-formatting-everywhere) for Minecraft 1.20.1 Fabric. It restores the section sign (`§`) in supported text-entry fields and keeps formatting codes when sign text is processed by the server.

## Compatibility

- Minecraft 1.20.1
- Fabric Loader 0.14.22 or newer
- Java 17 or newer
- Works on client and server. Install it on both sides when joining a modded server.
